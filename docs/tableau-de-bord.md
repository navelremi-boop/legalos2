# Tableau de bord — définition des indicateurs

Document cité par le jalon **Tableau de bord** (`PLAN.md`). Les formules exactes (période, HT ou TTC, facturé ou encaissé) et le jeu de test sont figés au moment de ce jalon ; ce fichier fixe le vocabulaire.

Ajustement du 30/10/2026 (Diligences) : l'indicateur « temps non facturé » devient « diligences non facturées », avec la part du temps passé.

## Indicateurs

| Indicateur | Objet (à préciser au jalon) |
| --- | --- |
| Chiffre d'affaires | Montants des factures sur la période retenue |
| Encours | Factures validées moins encaissements, par ancienneté |
| Diligences non facturées | Diligences libres et facturables ; part du temps passé nommée |
| Rentabilité par dossier | Rapport honoraires / temps (ou diligences) du dossier |
| Rentabilité par client | Agrégation des dossiers du client |
| Factures en erreur ou en attente sur la plateforme agréée | Statuts de transmission Factur-X / PA |
| Mails à classer | File locale des mails non classés |

Mention visible dans l'écran : chiffres calculés sur les dossiers accessibles à l'utilisateur.
